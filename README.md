# Calculadora de Empréstimo e Multas - Biblioteca Universitária

Projeto desenvolvido para a disciplina de **Testes Automatizados (ESW427)** do curso de **Engenharia de Software** da **Universidade de Rio Verde (UniRV)**.

* **Docente**: Profa. Vanessa Marques Alves da Silva Lima
* **Discente**: Yago Lemes da Cruz
* **Semestre**: 8º Período - 02/2026

## Sobre o Projeto
O componente `CalculadoraEmprestimo` gerencia:
- **RF01**: Elegibilidade de empréstimos, limites de livros simultâneos e prazos de devolução por perfil de usuário, considerando bloqueios por pendências e excedentes de limite.
- **RF02**: Cálculo progressivo de multas por atraso com faixas de isenção, cobrança linear e teto máximo de R$ 150,00.

O desenvolvimento foi conduzido integralmente sob o ciclo incremental do **Test-Driven Development (TDD)** e padrão **AAA (Arrange, Act, Assert)**.
